# Cartly exact SF Symbols slots

이 폴더는 `비슷한 아이콘` 금지용 exact asset 슬롯이다.

원칙:
- `CupertinoIcons` 근사치로 대체하지 않는다.
- 사용자가 지정한 SF Symbols를 SVG export로 받아 그대로 넣는다.
- 파일명은 앱 의미 기준으로 고정하고, 실제 심볼명은 별도 매핑으로 관리한다.
