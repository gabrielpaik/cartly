Cartly · private beta

장보기를 기록하고, 같은 구매 의도 안에서 더 나은 선택을 찾는 앱

Cartly는 스캔, 현재 카트, 저장된 장보기 기록을 바탕으로 사용자가 이미 사려던 상품과 같은 의도의 대체안을 다시 검토할 수 있게 도와줍니다.

작동 방식 보기 개인정보 안내
  • 상품 스캔 및 검토
  • 현재 카트와 저장된 장보기 기록 관리
  • 같은 구매 의도(same-intent) 기준 대체안 탐색
  • 사용자 탭 이후에만 외부 파트너 링크 열기
현재는 iOS private beta 기반으로 제품 흐름을 다듬고 있습니다.

Cartly가 하는 일

  1. Scan 상품을 촬영하거나 직접 추가합니다.
  2. Review 인식 결과를 검토하고 현재 카트에 담습니다.
  3. Explore 같은 상품군 안에서 다시 볼 후보와 대체안을 모읍니다.
  4. Save 장보기 결과를 저장해 다음 구매 의사결정에 활용합니다.

파트너 링크가 붙는 위치

Cartly는 무관한 크로스셀 피드 대신, 사용자가 이미 사려던 상품과 같은 구매 의도를 유지하는 대체안만 Explore 영역에서 보여주도록 설계되어 있습니다.

  • 최근 스캔 후 아직 확정하지 않은 상품
  • 현재 카트에 담긴 핵심 구매 후보
  • 반복 구매 가능성이 높은 저장 카트 품목

사용자 흐름

아래 흐름은 실제 앱에서 파트너 오퍼가 어떻게 맥락 안에서 노출되는지 설명하기 위한 개요입니다.

1. Scan inbox

스캔 후 검토

사용자는 스캔한 상품명을 확인하고 현재 카트에 넣거나 보류합니다.

2. Explore

같은 의도 대체안 확인

Explore 탭은 저장 기록, 현재 카트, 최근 스캔을 묶어 같은 상품군 대체안을 모읍니다.

3. Outbound

사용자 탭 후 외부 이동

외부 쇼핑 링크는 사용자가 특정 대체안을 선택했을 때만 열립니다.

현재 운영 상태

  • iOS private beta(TestFlight) 운영 중
  • OCR 스캔, 카트 저장, 반복 구매 맥락 정리 기능 포함
  • Explore 탭은 same-intent alternative 중심으로 고도화 중

파트너 검토 참고

  • 무작위 광고 피드가 아니라 장보기 의사결정 보조 흐름 안에 배치됩니다.
  • 사용자 액션 없이 외부 링크를 자동 실행하지 않습니다.
  • 제품 맥락과 구매 의도를 유지하는 대체안만 다룹니다.
